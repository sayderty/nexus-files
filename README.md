# Nexus Launcher — сборка и обновление модов

Лаунчер собирается у тебя на ПК (Windows), GitHub нужен только для раздачи файлов игрокам.

---

## 1. Сборка .exe

Нужен Node.js 20 LTS (nodejs.org). Затем:
- двойной клик по **build.bat**, либо в терминале папки: `npm install` и `npm run build`.

Результат в папке **dist**:
- `NexusLauncher-Setup.exe` — установщик: ставит лаунчер и создаёт ярлык на рабочем столе и в «Пуске». Раздавай игрокам его.
- `NexusLauncher.exe` — портативный, без установки.

Проверка без сборки: `npm start`.

**Перезаливать .exe при обновлении модов НЕ нужно** — только когда меняется сам лаунчер.

### Если сборка падает
- «Cannot create symbolic link» — запусти `build.bat` от администратора или включи Параметры → Для разработчиков → Режим разработчика, затем удали `%LOCALAPPDATA%\electron-builder\Cache` и повтори.
- Любая другая ошибка — скопируй текст из консоли.

## 2. Как обновить моды игрокам

1. Положи или удали файлы в `files\mods` (конфиги — `files\config`, дополнения Point Blank — `files\pointblank`). Новости — в `news.json`.
2. Двойной клик по **update-mods.bat**. Он пересоберёт `manifest.json` и отправит всё на GitHub.
   Вся работа внутри делает `release.js` (Node), сам `.bat` — четыре строки: так он не зависит
   от кодировки командной строки Windows.
   Без Git: `node release.js` соберёт манифест и подскажет, что делать дальше.
3. Игроки получат обновление при следующем нажатии «Играть» либо кнопкой **Обновить сборку** на вкладке «Сборка».

**Читай вывод `update-mods.bat`.** Он сам предупреждает о том, что обычно и ломает сборку:
- две версии одного мода в папке,
- файл тяжелее 95 МБ (GitHub такой не примет) или тяжелее 50 МБ (будет долго качаться),
- пробелы и кириллица в имени файла.

### Папка `files` — это папка игры
Что лежит в `files\X`, у игрока окажется в `%APPDATA%\.nexus-scp\X`. Поэтому:

| положить сюда | попадёт игроку в | для чего |
|---|---|---|
| `files\mods\*.jar` | `mods` | моды |
| `files\pointblank\*.zip` | `pointblank` | дополнения Point Blank (оружейные паки) |
| `files\config\*` | `config` | конфиги модов |

Из папок `mods` и `pointblank` у игроков **удаляется всё, чего нет в манифесте** — так уходят старые версии. Свои моды игроку класть туда бесполезно.

## 3. Что изменилось в обновлении модов

Раньше при каждой выдаче новой версии часть игроков получала «Файл скачивается повреждённым». Причина была не в файле: GitHub раздаёт через кеш, и какое-то время после загрузки он ещё отдаёт старые байты, а манифест уже новый. Отпечаток не сходился, лаунчер трижды качал то же самое и сдавался.

Что сделано:

- **Ссылки с отпечатком.** К каждому файлу дописывается отпечаток содержимого. Поменялся файл — поменялась ссылка, и кешу нечего подсунуть.
- **Зеркала.** Не ответил GitHub — файл берётся с jsDelivr или githack. Это тот же репозиторий, другая сеть доставки. Помогает игрокам, у которых GitHub открывается через раз.
- **Память о проверенных файлах.** Отпечатки запоминаются вместе с размером и временем изменения, пересчитываются только у изменившихся. Запуск со сборкой на сотни мегабайт больше не упирается в чтение диска.
- **Понятные отказы.** «Файл занят — закройте Minecraft», «мало места на диске», «не удалось скачать, вот что ответили зеркала» вместо кода ошибки.
- **Отчёт.** После обновления на вкладке «Сборка» видно, что добавлено, что обновлено и что удалено.

## 4. Дополнение Counter-Strike для Point Blank

Пак **уже лежит** в `files\pointblank\counterstrike_0_11_hotfix.zip` — игрокам он приедет сам при первом же обновлении.

**Важно: тот же файл нужен серверу.** Оружие регистрируется на обеих сторонах, иначе игроков будет выкидывать при входе.

На сервере:
1. Останови сервер.
2. Создай папку `pointblank` рядом с `mods` (в корне сервера, там же где `server.properties`).
3. Положи туда **тот же самый** `counterstrike_0_11_hotfix.zip`.
4. Запусти сервер. В логе появится строка о загрузке расширения Point Blank.

Проверить, что всё сошлось: зайди в игру и набери `/ammocheck` — наш мод покажет найденные стволы и подобранные к ним патроны.

Если понадобится обновить пак: положи новый `.zip` в `files\pointblank`, старый удали, запусти `update-mods.bat` — и замени файл на сервере. Версии должны совпадать.

## 5. Настройки `src/config.js`

`repo` (уже `sayderty/nexus-files`), `branch`, `forgeVersion` (как на сервере), `server`, `links`, `defaultRam`, `discordClientId`.

Forge, Java 17 и authlib-injector лаунчер скачивает сам.
Вход через Ely.by требует, чтобы сервер принимал такие аккаунты: authlib-injector на сервере (`https://authserver.ely.by/api/authlib-injector`) либо `online-mode=false` + AuthMe.

## 6. Если у игрока что-то не качается

1. Вкладка **Диагностика** → «Проверить». Она отдельно проверяет интернет, GitHub, манифест, Java, место на диске и целостность модов.
2. «Скопировать отчёт» — и прислать его.
3. Вкладка **Сборка** → «Обновить сборку»: качает только недостающее и показывает, что именно поменялось.
4. Логи: Настройки → Файлы → «Логи» (`%APPDATA%\.nexus-scp\logs\launcher.log`). Там записано, с какого зеркала какой файл приехал и что именно не получилось.
